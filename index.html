All four are paper-only proxies. No broker adapter, no API keys, no live orders. FVG Duo is an exact port of the video-derived Opening Drive + Trend FVG rules, run on the Dukascopy Nasdaq-100 CFD feed (not NQ futures). The cross-instrument OOS test did not validate the edge on S&P, Dow, or Russell, so this is a monitoring deployment, not a validated live strategy. Trend Trio is a video-derived proxy for the free SuperTrend / Ultimate MA / AlphaTrend rules; the video does not disclose every input, so open-source defaults are used. A 3-year NQ 1m proxy test was only PF 1.05 (net +$6.9k at 1 MNQ-equivalent, 12.8% max drawdown), so it is observation-only and not a validated edge.
